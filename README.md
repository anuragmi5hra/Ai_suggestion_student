# 📖 About Smart Study Planner

Smart Study Planner is a full-stack productivity application that helps students organize their study schedules, manage daily tasks, and improve learning efficiency. The application allows users to create personalized study plans, track progress, receive AI-powered study recommendations, and manage subjects through an intuitive and responsive interface.

---

# 🚀 Built With

Smart Study Planner was built using the following technologies:

- 🟢 Node.js
- 🚂 Express.js
- 🍃 MongoDB Atlas
- 🐍 Python (Flask AI Module)
- 📜 JavaScript (ES6+)
- 🎨 HTML5 & CSS3
- 🔐 JWT Authentication
- 📦 Mongoose
- 🤖 AI Study Recommendation System
- ☁️ Render
- 💻 VS Code

# 🛠 Getting Started

Clone the repository

```bash
git clone https://github.com/anuragmi5hra/Ai_suggestion_student
```

Move into the project directory

```bash
cd Smart-Study-Planner
```

---

# 📦 Installation

Install dependencies

```bash
npm install
```

---

# ▶️ Running the Application

### Frontend

```bash
npm run dev
```

### Backend

```bash
npm start
```

or

```bash
nodemon server.js
```

### AI Server (Flask)

```bash
python app.py
```
